# Sistema de Avaliação Escolar

Projeto simples desenvolvido em Portugol para praticar lógica de programação.

## Funcionalidades

O programa:

- Solicita o nome do aluno
- Recebe quatro notas
- Valida se as notas estão entre 0 e 10
- Calcula a média final
- Informa se o aluno foi aprovado, recuperação ou reprovado
